Integrales Hiperbólicas Inversas

Cuando el denominador contiene raíces de sumas o restas de cuadrados, las funciones hiperbólicas inversas son la herramienta perfecta para encontrar el área.

Fundamento Teórico

La Conexión Logarítmica

Las funciones \operatorname{arcsinh} y \operatorname{arccosh} pueden expresarse con logaritmos naturales. Por eso estas integrales también aparecen escritas en forma logarítmica en muchos textbooks: son la misma respuesta.

El Signo Decide Todo

La clave está dentro de la raíz: u^2 + a^2 (suma) conduce a \operatorname{arcsinh}, mientras que u^2 - a^2 (resta) conduce a \operatorname{arccosh}. Si la resta está invertida, a^2 - u^2, es \arcsin (Módulo 11).

Fórmulas Maestras

Arcoseno Hiperbólico

\int \frac{du}{\sqrt{u^2 + a^2}} = \operatorname{arcsinh}\left(\frac{u}{a}\right) + C

Arcocoseno Hiperbólico

\int \frac{du}{\sqrt{u^2 - a^2}} = \operatorname{arccosh}\left(\frac{u}{a}\right) + C \quad (u \gt a)

Arcotangente Hiperbólica

\int \frac{du}{a^2 - u^2} = \frac{1}{a}\operatorname{arctanh}\left(\frac{u}{a}\right) + C \quad (|u| \lt a)
Equivalencias Logarítmicas
\operatorname{arcsinh}(x) = \ln\left(x + \sqrt{x^2 + 1}\right)
\operatorname{arccosh}(x) = \ln\left(x + \sqrt{x^2 - 1}\right), \; x \ge 1
\operatorname{arctanh}(x) = \tfrac{1}{2}\ln\left(\frac{1+x}{1-x}\right), \; |x| \lt 1
Guía Rápida: ¿Cuál Fórmula Uso?

Ejemplos Resueltos Paso a Paso

1
Ejemplo Básico: \displaystyle\int \frac{dx}{\sqrt{x^2+9}}

PASO 1: Identificar a y u

La expresión es \sqrt{x^2+3^2}, por lo tanto a = 3 y u = x. Como u = x, entonces du = dx.

PASO 2: Aplicar la fórmula

\int \frac{du}{\sqrt{u^2 + a^2}} = \operatorname{arcsinh}\left(\frac{u}{a}\right) + C

Resultado Final

\operatorname{arcsinh}\left(\frac{x}{3}\right) + C \;=\; \ln\left(x+\sqrt{x^2+9}\right) + C

Comprobación (derivando)

\frac{d}{dx}\operatorname{arcsinh}\left(\frac{x}{3}\right) = \frac{1}{\sqrt{x^2+9}} \;\checkmark
2
Ejemplo Intermedio: \displaystyle\int \frac{dx}{\sqrt{4x^2-25}}

PASO 1: Reescribir e identificar

Tenemos \sqrt{(2x)^2 - 5^2}, entonces a = 5 y u = 2x. Derivamos: du = 2\,dx \implies dx = \frac{du}{2}.

PASO 2: Sustituir

\int \frac{du/2}{\sqrt{u^2 - 5^2}} = \frac{1}{2}\operatorname{arccosh}\left(\frac{u}{5}\right) + C

Resultado Final

\frac{1}{2}\operatorname{arccosh}\left(\frac{2x}{5}\right) + C
Dominio: válido solo para x \gt \tfrac{5}{2}, pues \operatorname{arccosh} exige argumento mayor que 1.
3
Ejemplo Avanzado: \displaystyle\int \frac{e^x}{\sqrt{e^{2x}-16}}\,dx

PASO 1: Elegir sustitución

Notamos que e^{2x} = (e^x)^2. Elegimos u = e^x, entonces du = e^x\,dx. ¡El numerador encaja perfecto!

PASO 2: Transformar

La integral se convierte en \displaystyle\int \frac{du}{\sqrt{u^2-4^2}} con a=4.

PASO 3: Integrar y volver a x

\operatorname{arccosh}\left(\frac{u}{4}\right) + C \;=\; \operatorname{arccosh}\left(\frac{e^x}{4}\right) + C

Válido para e^x \gt 4, es decir x \gt \ln 4.

Truco de examen: el signo dentro de la raíz decide todo. u^2+a^2 \rightarrow \operatorname{arcsinh}, u^2-a^2 \rightarrow \operatorname{arccosh}, a^2-u^2 \rightarrow \arcsin (con raíz) o \operatorname{arctanh} (sin raíz).
