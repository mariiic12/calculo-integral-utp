Trinomio ax² + bx + c

Completar el cuadrado es la llave maestra: convierte cualquier trinomio en una forma que ya sabes integrar (arctan, arcsinh, arccosh o logaritmo).

Fundamento Teórico

La Idea: Completar el Cuadrado

Tomamos la mitad del coeficiente b, la elevamos al cuadrado y la sumamos y restamos. Así el trinomio se reescribe como un binomio al cuadrado más una constante: (x+m)^2 \pm p^2, que es exactamente la forma de los módulos 11 y 12.

El Discriminante Decide

El signo de \Delta = b^2 - 4ac anticipa el destino de la integral: si \Delta \lt 0 aparecen arctan o arcsinh; si \Delta \gt 0 aparecen logaritmos o arctanh; y si \Delta = 0 queda una potencia simple.

Identidad de Completación
ax^2 + bx + c \;=\; a\left[\left(x + \frac{b}{2a}\right)^2 - \frac{\Delta}{4a^2}\right], \qquad \Delta = b^2 - 4ac
Las Tres Formas Resultantes

Caso \Delta \lt 0 (sin raíces reales)

\int \frac{dx}{(x+m)^2 + p^2} = \frac{1}{p}\arctan\left(\frac{x+m}{p}\right) + C

Caso \Delta = 0 (cuadrado perfecto)

\int \frac{dx}{(x+m)^2} = -\frac{1}{x+m} + C

Caso \Delta \gt 0 (dos raíces reales)

\int \frac{dx}{(x+m)^2 - p^2} = \frac{1}{2p}\ln\left|\frac{x+m-p}{x+m+p}\right| + C

Ejemplos Resueltos Paso a Paso

1
Ejemplo Básico (\Delta \lt 0): \displaystyle\int \frac{dx}{x^2+6x+13}

PASO 1: Completar el cuadrado

Mitad de 6 es 3, y 3^2=9. Entonces x^2+6x+13 = (x+3)^2 + 4. Aquí m=3 y p=2.

PASO 2: Sustituir u=x+3

\int \frac{du}{u^2 + 2^2} = \frac{1}{2}\arctan\left(\frac{u}{2}\right) + C

Resultado Final

\frac{1}{2}\arctan\left(\frac{x+3}{2}\right) + C

Comprobación (derivando)

\frac{d}{dx}\left[\frac{1}{2}\arctan\left(\frac{x+3}{2}\right)\right] = \frac{1}{x^2+6x+13} \;\checkmark
2
Ejemplo Intermedio (con raíz): \displaystyle\int \frac{dx}{\sqrt{x^2+4x+8}}

PASO 1: Completar el cuadrado

Mitad de 4 es 2, y 2^2=4. Entonces x^2+4x+8 = (x+2)^2 + 4, es decir u^2 + p^2 con u=x+2, p=2.

PASO 2: Reconocer la forma hiperbólica

\int \frac{du}{\sqrt{u^2 + 2^2}} = \operatorname{arcsinh}\left(\frac{u}{2}\right) + C

Resultado Final

\operatorname{arcsinh}\left(\frac{x+2}{2}\right) + C \;=\; \ln\left(x+2+\sqrt{x^2+4x+8}\right) + C

Ambas formas son correctas: la logarítmica es la equivalencia del Módulo 12.

3
Ejemplo Avanzado (\Delta \gt 0): \displaystyle\int \frac{dx}{x^2-2x-8}

PASO 1: Completar el cuadrado

Mitad de -2 es -1, y (-1)^2=1. Entonces x^2-2x-8 = (x-1)^2 - 9, con u=x-1 y p=3.

PASO 2: Aplicar la forma logarítmica

\int \frac{du}{u^2 - 3^2} = \frac{1}{6}\ln\left|\frac{u-3}{u+3}\right| + C

Resultado Final

\frac{1}{6}\ln\left|\frac{x-4}{x+2}\right| + C
Dominio: la función diverge en las raíces x=-2 y x=4; integra solo en intervalos que no las contengan.
Truco de examen: antes de completar el cuadrado, revisa el numerador. Si es la derivada del trinomio (2x+b), la integral es simplemente \ln|x^2+bx+c| (Módulo 9) y te ahorras todo el proceso.
