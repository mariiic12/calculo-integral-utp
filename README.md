# 📐 Plataforma de Matemáticas 2 - UTP

Plataforma web interactiva para el aprendizaje de métodos numéricos y técnicas de integración del cálculo integral.

## 🎯 Descripción

Este proyecto es parte de la evaluación del curso de Matemáticas II de la Universidad Tecnológica de Pereira. La plataforma está diseñada para ayudar a los estudiantes a visualizar y comprender conceptos fundamentales del cálculo integral mediante visualizaciones interactivas y ejemplos resueltos paso a paso.

## 📚 Módulos

### Sección A: Métodos Numéricos
1. **Sumas de Riemann** - Aproximación mediante sumas izquierda, derecha y punto medio
2. **Regla del Trapecio** - Aproximación mediante trapecios
3. **Regla del Punto Medio** - Aproximación mediante rectángulos de punto medio
4. **Regla de Simpson** - Aproximación mediante parábolas
5. **Integral Definida y Área** - Teorema Fundamental del Cálculo
6. **Integración Directa** - Fórmulas básicas de integración

### Sección B: Métodos de Integración (Próximamente)
7. Sustitución/Potencias
8. Exponenciales
9. Logarítmicas
10. Trigonométricas
11. Trigonométricas Inversas
12. Hiperbólicas Inversas
13. Trinomio ax²+bx+c
14. Integración por Partes

## 🚀 Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con variables CSS y diseño responsive
- **JavaScript (ES6+)** - Lógica interactiva
- **KaTeX** - Renderizado rápido de fórmulas matemáticas
- **Plotly.js** - Visualizaciones interactivas
- **GitHub Pages** - Despliegue
