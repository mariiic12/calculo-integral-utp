> Plataforma web interactiva para el aprendizaje de métodos numéricos y técnicas de integración del cálculo integral, desarrollada como proyecto del curso de Matemáticas II de la Universidad Tecnológica de Pereira.

---

## 🎯 Descripción

Este proyecto es la **Fase 1** de un proyecto semestral colaborativo. La plataforma está diseñada para ayudar a los estudiantes a visualizar y comprender conceptos fundamentales del cálculo integral mediante:

- ✅ Visualizaciones interactivas con Plotly.js
- ✅ Fórmulas matemáticas renderizadas con KaTeX
- ✅ Ejemplos resueltos paso a paso
- ✅ Diseño responsive y modo oscuro
- ✅ Arquitectura modular escalable

## 🚀 Tecnologías Utilizadas

### Frontend

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con variables CSS y diseño responsive
- **JavaScript (ES6+)** - Lógica interactiva y manipulación del DOM

### Frameworks y Librerías

- **Bootstrap 5.3.2** - Framework CSS para diseño responsive
- **Bootswatch (Zephyr)** - Tema personalizado de Bootstrap
- **Bootstrap Icons 1.11.2** - Iconos SVG integrados
- **KaTeX 0.16.9** - Renderizado rápido de fórmulas matemáticas
- **Plotly.js 2.27.0** - Visualizaciones interactivas
- **AOS (Animate On Scroll) 2.3.4** - Animaciones al hacer scroll

### Tipografía

- **Google Fonts** - Inter y Space Grotesk

### Herramientas de Desarrollo

- **Git** - Control de versiones
- **GitHub** - Repositorio remoto y colaboración
- **GitHub Pages** - Despliegue y hosting gratuito
- **VS Code** - Editor de código
